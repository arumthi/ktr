# மதிப்பு சங்கிலி நிதியளிப்பு (VCF): பண்ணை முதல் தொழிற்சாலை வரை

---

## 🎯 நிர்வாহக சுருக்கம்

மதிப்பு சங்கிலி நிதியளிப்பு (VCF) என்பது விவசாய உৎপादन, செயல்முறை மற்றும் விநியோগ செயல்முறையில் நேரடியாக நிதிசேவைகளை ஒருங்கிணைக்கிறது. பாரம்பரிய உடல் உபகரண-அடிப்படையிலான கடன் வழங்குதলுக்கு பதிலாக, வங்கிகள் ভবிষ்யতের விற்பனை ஒப்பந்தத்தை 担보 (担保) ஆக பயன்படுத்துகின்றன.

```
┌──────────┐     விநியோग ஒப்பந்தம்     ┌──────────────┐
│  விவசாயி  │ <─────────────────────> │ உற்பత்তியாளர │
└────┬─────┘                         └──────┬───────┘
     │                                      │
     │ ஒப்பந்தத்தை அடிப்படையாக         │ நேரடி கடன்
     │ கடன் வழங்குதல்                    │ தீர்வு
     ▼                                      ▼
┌──────────────────────────────────────────────────┐
│           நிதி நிறுவனம்                      │
└──────────────────────────────────────────────────┘

```

---

## ⚙️ VCF எவ்வாறு செயல்படுகிறது: 3-வழி கூட்டாண்மை

```
   1. ஒப்பந்தத்தில் கையெழுத்து     2. கடன் நீட்டிக்க
   [விவசாயி] <──────────────> [உற்பத்தியாளர] <──────────────> [வங்கி]
      │                           ▲                              ▲
      │    3. பயிர் வழங்கிக      │   4. நேரடி தீர்வு        │
      └───────────────────────────┴──────────────────────────────┘

```

1. **ஒப்பந்தம்:** ஒரு உள்ளூர் செயல்முறை ஆலை அல்லது மில் விவசாயியுடன் ஒரு சட்டப்பூர்வ ক্রয় ஒப்பந்தத்தில் கையெழுத்து செய்கிறது, சம்மதிக்கப்பட்ட விலையில்.

2. **கடன்:** ஒரு கடன் சहकारी அல்லது கிராமப்புற வங்கி அந்த முறையான ஒப்பந்தத்தை கடன்담보 (担保) ஆக பயன்படுத்தி, உள்ளீட்டு செலவுகளுக்கான மூலதனத்தை முன்னிட்டு வழங்குகிறது (விதைகள், உரம், உபகரணங்கள்).

3. **தீர்வு:** அறுவடை நேரத்தில், விவசாயி உற்பத்தியாளரக்கு பயிரை வழங்குகிறார். உற்பத்தியாளர் கடன் நிலுவையை வங்கிக்கு நேரடியாக செலுத்துகிறார் மற்றும் எஞ்சிய லாபத்தை விவசாயிக்கு அனுப்புகிறார்.

## 💎 உள்ளூர் பொருளாதாரத்தின் முக்கிய நன்மைகள்

* **担保 (担保) மாற்று:** நிலமற்ற விவசாயிகள் மற்றும் சிறு பண்ணைக்காரர்கள் சொத்து தலைப்புக்கு பதிலாக உத்தரவாதப்பட்ட ভবிষ்யற்கால விற்பனையின் அடிப்படையில் முறையான கடனை அணுக முடியும்.

* **குறைந்த கடன் செலவுகள்:** நேரடி தீர்வு கட்டமைப்புகள் கடனদাতা இருப்பு ஆபத்தை குறைக்கிறது, வட்டி விகிதம் போட்டி நிறுவన மட்டத்திற்கு குறைக்கிறது.

* **சப்ளை சங்கிலி நிலைத்தன்மை:** விவசாயிகளுக்கு உத்தரவாதப்பட்ட விற்கிற வழங்கலை வழங்கிக, உள்ளூர் உற்பத்தி செயல்முறைக்கு சரியான பொருட்களின் ஒரு நிலையான ஓட்டத்தை பாதுகாக்கிறது.
