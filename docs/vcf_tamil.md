# மதிப்புக் சங்கிலி நிதி உதவி (Value Chain Financing - VCF): பண்ணையிலிருந்து தொழிற்சாலை வரை இணைத்தல்

---

## 🎯 நிர்வாகச் சுருக்கம் (Executive Summary)

மதிப்புக் சங்கிலி நிதி உதவி (VCF) என்பது விவசாய உற்பத்தி, பதப்படுத்துதல் மற்றும் விநியோக செயல்முறைகளில் நிதிச் சேவைகளை நேரடியாக ஒருங்கிணைக்கிறது. பாரம்பரிய நிலம் போன்ற சொத்துப் பிணையங்களை மட்டுமே நம்பியிருக்காமல், விவசாயிகள் மற்றும் பதப்படுத்தும் தொழிற்சாலைகளுக்கு இடையே உள்ள ஒப்பந்தங்கள் மற்றும் வணிக உறவுகளின் வலிமையை அடிப்படையாகக் கொண்டு வங்கிகள் இதன் கடனுதவியை மதிப்பிடுகின்றன.

```
┌──────────┐      விநியோக ஒப்பந்தம்     ┌──────────────┐
│ விவசாயி  │ <─────────────────────> │ உற்பத்தியாளர்│
└────┬─────┘                         └──────┬───────┘
     │                                      │
     │ ஒப்பந்தத்தின்                         │ நேரடி கடன்
     │ அடிப்படையில் கடன்                  │ தீர்வு (Settlement)
     ▼                                      ▼
┌──────────────────────────────────────────────────┐
│                   நிதி நிறுவனம்                  │
└──────────────────────────────────────────────────┘


```

## ⚙️ VCF இயங்கும் முறை: 3 வழி கூட்டாண்மை

```
   1. ஒப்பந்தம் செய்தல்          2. கடன் வழங்குதல்
   [விவசாயி] <──────────────> [உற்பத்தியாளர்] <──────────────> [வங்கி]
      │                           ▲                           ▲
      │     3. பயிர் விநியோகம்    │   4. நேரடி கடன் தீர்வு    │
      └───────────────────────────┴───────────────────────────┘


```

1. **ஒப்பந்தம் (The Contract):** உள்ளூர் பதப்படுத்தும் ஆலை அல்லது மில், விவசாயியுடன் ஒப்புக் கொள்ளப்பட்ட விலையில் ஒரு பிணைப்புள்ள கொள்முதல் ஒப்பந்தத்தில் கையெழுத்திடுகிறது.
2. **கடன் (The Credit):** கடன் கூட்டுறவுச் சங்கம் அல்லது கிராமப்புற வங்கி, அந்த முறைசார்ந்த ஒப்பந்தத்தைப் பிணையமாகப் பயன்படுத்தி, ஆரம்பக்கட்ட செலவுகளுக்காக (விதைகள், உரங்கள், உபகரணங்கள்) மூலதனக் கடனை வழங்குகிறது.
3. **கடன் தீர்வு (The Settlement):** அறுவடைக்குப் பிறகு, விவசாயி தனது விளைபொருட்களை உற்பத்தியாளரிடம் ஒப்படைக்கிறார். உற்பத்தியாளர் கடனுக்கான தொகையை நேரடியாக வங்கிக்குச் செலுத்திவிட்டு, மீதமுள்ள லாபத்தை விவசாயியிடம் வழங்குகிறார்.

## 🛠️ செயலாக்க மாதிரிகள் (Implementation Models)

| மாதிரி (Model) | முதன்மை நிதியளிப்பவர் | இயங்கும் முறை | எதற்கு ஏற்றது? |
| --- | --- | --- | --- |
| **வர்த்தகர் வழிகாட்டும் / ஒப்பந்த விவசாயம்** | உற்பத்தியாளர் / பதப்படுத்துபவர் | தொழிற்சாலை நேரடியாக கடனில் தேவையானப் பொருட்களை வழங்குகிறது; அதன் செலவுகள் இறுதி பயிர் பேஅவுட்டில் (Payout) கழித்துக் கொள்ளப்படும். | அதிக மதிப்புள்ள பணப்பயிர்கள் அல்லது சிறப்பு கால்நடை வளர்ப்பு முறைகள். |
| **கிடங்கு ரசீது நிதி (Warehouse Receipt)** | வங்கி அல்லது கூட்டுறவு சங்கம் | விளைபொருட்கள் அங்கீகரிக்கப்பட்ட கிடங்குகளில் சேமிக்கப்படும்; ரசீதுகள் 60%–80% முன்பணக் கடனுக்கான பிணையமாகப் பயன்படும். | அறுவடைக்குப் பின் சந்தை விலைகள் ஏற்ற இறக்கமாக இருக்கும் பருவகால தானியங்கள்/அத்தியாவசிய பயிர்கள். |
| **பெறவேண்டிய கணக்குகள் நிதி (Factoring)** | வர்த்தக வங்கி | ஆலைக்கு உடனடியாகத் தேவையான வேலை மூலதனத்தைப் பெற, வாடிக்கையாளர்களின் நிலுவையில் உள்ள விலைப்பட்டியல்களை (Invoices) சலுகை விலையில் வங்கி வாங்கிக் கொள்ளும். | வாங்குபவரின் 60-90 நாள் கட்டண விதிமுறைகளுக்காகக் காத்திருக்கும் உள்ளூர் பதப்படுத்தும் ஆலைகள். |

## 💎 உள்ளூர் பொருளாதாரத்திற்கான முக்கிய நன்மைகள்

* **மாற்று பிணைய முறை:** நிலமற்ற விவசாயிகள் மற்றும் சிறு விவசாயிகள், சொத்துப் பத்திரங்களுக்குப் பதிலாகத் தங்களின் உறுதியான எதிர்கால விற்பனையை அடிப்படையாகக் கொண்டு முறைசார்ந்த வங்கிக் கடன்களைப் பெற முடிகிறது.
* **குறைக்கப்பட்ட கடன் செலவுகள்:** நேரடி கடன் தீர்வு முறைகள் கடன் வழங்குபவரின் ஆபத்தைக் (Default Risk) குறைப்பால், வட்டி விகிதங்கள் கணிசமாகக் குறைகின்றன.
* **சப்ளை சேயின் நிலைத்தன்மை:** விவசாயிகளுக்கு உறுதியான விற்பனை வாய்ப்பை உறுதி செய்வதோடு, உள்ளூர் உற்பத்தி ஆலைகளுக்குத் தேவையான மூலப்பொருட்களின் தொடர்ச்சியான விநியோகத்தையும் உறுதி செய்கிறது.
